MCP servers

One entry per server. Local servers run through the bridge, so use http://127.0.0.1:3939/mcp/NAME with the same name as in the bridge's servers.json. Remote servers use their own URL and optional headers. Names may contain letters, digits, _ and -.




Always-allowed tools


These run without asking. Keep this list to tools that only read data.

Skills


A skill is a folder with a SKILL.md (a name: and description: header, then instructions) and optional reference files such as references/guide.md. Only names and descriptions go into the inserted text. Gemini loads a skill's instructions when a task matches it, and opens its reference files when the instructions point to them.



  
  
  
  



Pick one skill's folder, or a parent folder holding many skills: every folder inside it that has a SKILL.md becomes a skill. Text files up to 1 MB are kept; images and other binary files are skipped. Importing a skill again replaces it.





Project memory


Facts kept per project and added to the inserted text. Gemini can ask to add one (you approve it). Pick the project from the MCP menu in AI Studio.
